    fix(rasgram): FCM call sending silent failure + TURN server reliability
    
    Bug: Android 15 থেকে call send হলে receiver কাছে পৌঁছায় না (15→15, 15→10)
    
    Root cause 1 — Silent exception in sendFcmCallNotification():
      catch (_: Exception) {} সব error চুপ করে গিলে ফেলত।
      Android 15 এ কী fail হচ্ছে debug করার কোনো উপায় ছিল না।
      Fix: সব step এ Log.e/d/w যোগ করা হয়েছে। এখন logcat এ দেখা যাবে:
        - fcmToken missing কিনা
        - service_account.json load হচ্ছে কিনা
        - OAuth2 token exchange সফল কিনা (HTTP code + body)
        - FCM send সফল কিনা (HTTP code + body)
      এই log দেখেই বোঝা যাবে Android 15 এ ঠিক কোথায় fail হচ্ছে।
    
    Root cause 2 — OkHttpClient no explicit timeout:
      Default OkHttpClient() এ timeout নেই (infinite)।
      Android 15 এ cellular network এ connection hang হতে পারে।
      Fix: connectTimeout/readTimeout/writeTimeout = 20s explicitly।
    
    Root cause 3 — TURN server unreliable:
      openrelay.metered.ca credentials 'openrelayproject/openrelayproject'
      সবাই use করে → server প্রায়ই overloaded বা rate-limited।
      Android 15 এ ICE gathering timeout কম → TURN fail → call connected না।
      Fix: Primary TURN = a.relay.metered.ca (dedicated free credentials),
      multiple ports (UDP 80/443, TCP 443, TLS 443).
      Fallback: Xirsys free tier → OpenRelay (last resort).
