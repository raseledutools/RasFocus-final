👨‍👧 Parental Control

সন্তানকে সুরক্ষিত রাখুন

Firebase-powered real-time parental control — ঘরে বসে বা দূরে থেকেও সন্তানের ফোন monitor করুন।

  • 📱
    Remote App Blocking Firebase-এর মাধ্যমে instantly যেকোনো app block করুন child device-এ।
  • ⏰
    Screen Time Limit Daily screen time limit set করুন — limit শেষে ফোন automatically lock হবে।
  • 📸
    Remote Screenshot যেকোনো সময় command দিয়ে সন্তানের screen-এর screenshot নিন।
  • 🔴
    Adult Content Block Keywords-based intelligent adult content filtering। Firebase-থেকে keyword sync।
  • 🌐
    Website & Reels Control Shorts, Reels, specific websites remotely on/off করুন।
  • 📊
    Real-time Monitoring Child device-এর stats, blocked apps, usage — সব real-time দেখুন।
